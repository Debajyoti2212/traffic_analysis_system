System Architecture & Overview

Smart Traffic & Violation Management System

v2.1

1. Computer Vision Pipeline (OpenCV & YOLO)

Processes live intersection video feeds to detect vehicles, track motion using Euclidean centroid distance, recognize virtual stop-line boundaries, and identify red-light jumps, helmetless riding, and seatbelt violations.

2. Automated e-Challan & Emergency Override

Captures violation snapshots with timestamps and penalties. Detects emergency vehicles (ambulances, fire trucks) to activate Green Corridor priority signals.

3. Citizen Grievance NLP Triage

Classifies unstructured citizen complaints into CRITICAL, MODERATE, and LOW urgency tiers using linguistic analysis and keyword semantic vector matching.

Backend: FastAPI + Python + OpenCV (Port 8000)
Frontend: Glassmorphic Bento UI Dashboard
Tracking: Centroid Euclidean Multi-Object Tracker
